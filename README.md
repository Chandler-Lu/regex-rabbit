# Regex Rabbit

Chrome Manifest V3 页面搜索插件，当前版本 4.5.0。点击工具栏图标，或按 `Ctrl+Shift+F`（macOS 为 `Command+Shift+F`）打开搜索栏。运行需要 Chrome 116 或更新版本。

隐私政策见 [PRIVACY.md](PRIVACY.md)。

搜索栏保持单行：左侧拖柄、输入框、`.*` 正则开关、`Aa` 大小写开关、计数、上下箭头、`⋮` 更多选项和关闭。输入后自动查找并标记结果，保持当前视口；按 `Enter` 定位当前结果，再按 `Enter` 到下一处，`Shift+Enter` 到上一处。点击计数可输入 1 到当前有效结果总数之间的序号，按 `Enter` 定位；`Esc` 或失去焦点取消输入。更多选项弹出时不撑高主栏，靠近窗口底部时向上展开；窄窗口中部分开关和导航可在其中操作。菜单打开时 `Esc` 先关闭菜单；随后清空查询，查询为空时关闭搜索栏。关闭时尽量恢复原来控件的焦点。错误提示浮在下方，悬停可查看详细说明。界面支持浅色、深色和窄窗口，样式通过用户来源 CSS 保护，尺寸限制按缩放换算。

更多选项提供范围“全页 / 选区”、整词、自动更新、正则专用的 `m` 多行锚点和 `s` 跨换行匹配，以及设置入口；模式和大小写只在主栏开关隐藏时出现在菜单中。整词匹配使用 Unicode 字母、数字、组合标记、连接标点及零宽连接符判断字符边界，不等同于完整的语言分词。先选中网页文字、文本输入框或 textarea 内的字符，再打开搜索栏并选择“选区”，即可限定查询范围。支持同源 iframe 和可访问 Shadow DOM 中的选区；控件值发生变化或所属 iframe 已脱离页面后，旧选区不能继续使用。

设置页可以调整默认模式、颜色和缩放，展开“更多设置”后调整自动更新等待、扫描量、超时时间和匹配上限，也可选择“轻量”“均衡”“大页面”预设。界面语言默认跟随浏览器，可选择简体中文、繁体中文、英语、日语、韩语、德语、法语或西班牙语。颜色提供预览并保留透明色的原格式，无效输入会阻止保存。恢复默认后需保存才能应用。读取设置失败时禁止保存，重试读取会保留尚未保存的修改。

拖动左侧细柄可移动搜索栏；拖柄获得焦点时可用方向键微调，`Home` 恢复默认位置。默认只保留当前页面的位置，关闭再打开仍保留，刷新或进入新页面后复位。开启“永久记忆位置”后，位置在浏览器本地保存，可在其他页面及重启后复用；关闭此设置会删除保存的位置，本页当前位置仍保留。拖动和窗口大小变化时，搜索栏限制在可见范围内。

## 搜索范围

采集按页面的实际显示顺序遍历普通 DOM、Shadow DOM、slot 分配内容及可访问的同源 iframe。屏幕外仍可滚动到的文字参与搜索；脚本、样式、隐藏子树、关闭的 details 正文、密码、Canvas 的备用内容和 SVG 定义不参与搜索。`aria-hidden` 本身不隐藏文字，因此不会单凭这个属性排除视觉上存在的文本。

Chrome 扩展通过 [openOrClosedShadowRoot API](https://developer.chrome.com/docs/extensions/reference/api/dom) 读取开放和闭合的 ShadowRoot，接口不存在时保留标准开放根支持。原生输入和密码控件的内部根不参与遍历。

同一个文本块内的连续行内节点合并查询，避免页面把一个词拆成多个 span 后无法找到。普通 CSS 空白折叠后按可见文字搜索，并保留原始字符位置；现代 `white-space-collapse` 与换行方式也参与归一化。Ruby 基字可跨注音元素匹配，注音文字单独查询；保留空白的文本块仍保留换行。连续行内 Shadow DOM 和 slot 内容可以共同形成一个结果。不同块、iframe 和显式换行边界不会拼接。表单搜索使用当前可见值、单选下拉框的显示标签及可见占位文字，编辑区域使用当前文字。普通文字通过 Range 和 CSS Custom Highlight 绘制，原始文本节点保持不变；没有这项 API 时使用数量受限的透明矩形层。文本控件的内部文字无法用 DOM Range 绘制，定位到结果时选中对应字符；下拉标签和占位文字定位到相应控件，不修改表单值。

浏览器不向这个插件开放跨域或 sandbox 隔离的 iframe、浏览器内部页面、Canvas 像素文字、图片文字和 PDF 查看器内容。CSS 伪元素生成文字、复杂语言相关的视觉文字变换、尚未挂载的虚拟列表内容也不能保证有准确字符位置。多选或展开的原生列表框，以及没有显式 value 的浏览器本地化按钮标签，目前没有可靠的显示文字映射。计数提示会标出无法访问的 iframe、扫描截断，以及渲染前已隐藏或变化的结果。采集期间的 DOM 变化、结果所属根移动和 iframe 脱离都会使相关旧结果失效；动态页面中可重新查询。没有读取到的内容不会作为已搜索内容报告。

## 动态页面

开启“自动更新”后，观察文字、节点和影响显示的属性变化，并监听表单、slot、details、frame 加载和窗口尺寸变化。它只在当前页面会话中启用，持久设置不会自动开启。分批巡检补充新建 ShadowRoot、脚本直接修改的表单值，以及可读 CSSOM 规则的变化；覆盖样式表媒体条件、系统媒体条件变化、URL fragment、有效性及 indeterminate 状态。只有相关样式存在或样式表不可读时，指针悬停和按下事件才触发查询；跨域样式表规则无法读取。巡检保留进度，下一批继续检查尚未访问的根、控件和样式，不按这些对象的数量截断范围。长控件值分片检查，共享原字符串引用。大页面、长文字和大样式表需要多次巡检才能检查完，更新并非即时发生。脚本直接修改 CSSOM 来显示原本隐藏的文字间隔时，旧结果可能要等自动更新巡检才失效；未启用自动更新时需重新查询。

连续变化有最长等待时间，避免一直推迟查询。输入、切换搜索选项、设置变化和自动更新只刷新标记，不主动滚动；除新输入外，更新尽量保留当前命中。已定位的当前命中仍在时，`Enter` 继续前往下一处；自动更新或选项刷新过程中按下 `Enter`，会等结果可用后定位或切换。显式定位时，即使当前命中已在视口内，也尽量将其横向、纵向居中；页面或容器边缘按实际可滚动范围限制，并避开搜索栏。定位检查内层滚动容器和 iframe，仅排队一次动画帧并即刻滚动，避免多次延时定位拉回页面；用户滚轮、触摸、按下指针或滚动按键会取消尚未执行的定位。网页自身的滚动或布局变化仍可能影响位置。

标签页转入后台时暂停自动更新、查询和待执行定位；回到前台后补上未完成的输入查询，若启用了自动更新，还会重新查询以补上后台期间的页面变化。页面替换 body 时，保留查询并恢复搜索栏；连续替换时逐步延迟恢复，最多等待 2 秒，页面稳定后仍可恢复。按 Esc 或关闭搜索栏会取消待执行恢复。关闭时停止观察、计时器、选区监听和搜索任务。前进或后退恢复缓存页面时，会重新查询并保持视口。

## 查询设置与执行

正则只在可终止的独立 Worker 中匹配。Chrome 扩展的 offscreen 文档承载 Worker，网页的 `worker-src` 限制不会使查询降级到网页主线程。此机制需要 `offscreen` 权限；页面读取仍使用用户点击授予的 `activeTab`，运行包没有新增全站访问权限。页面内容仅在插件本地传递，不发送到网络服务。

静态规则会拦截部分容易产生大量回溯的表达式，但不承担全部执行安全。超过 8192 个字符的正则，其风险检查和编译在 Worker 内进行。扩展自定义拦截规则只允许最长 512 字符的固定序列、简单字符类、安全转义和锚点，拒绝重复、分组、分支、环视和回引，避免规则本身在主线程发生大量回溯。整次查询共用一个时限，覆盖准备、启动、传输、采集、匹配和标记，各阶段使用剩余时间，不另设每批或每块的执行时限。匹配超时会终止 Worker，随后可以重新查询。offscreen 创建与关闭 API 挂起时，启动任务也会在有限期限内结束，后续查询可以重试；非法终态结果不会进入渲染。任务按批确认，每次只有一批等待处理，避免生产文本的速度高于匹配速度时无限堆积。确认后释放没有命中的节点映射，只保留命中所需的数据。

查询上限为 4,096,000 个字符，默认总扫描预算为 32,000 Mi 字符，设置页可提高到 64,000 Mi 字符，不再设单块字符配额。这里的字符数按 UTF-16 代码单元计算，1 Mi 为 1,048,576。默认整次查询时限为 5000 ms，可提高到 900000 ms（15 分钟）；默认最多显示 9999 个命中，可提高到 20000 个。升级时，尚未迁移的旧扫描预算按 1000 倍读入；保存设置后，新输入的小预算不会再次扩大，旧单块设置不再生效。

页面搜索的结束条件由扫描字符数、整次查询时限和匹配上限控制；节点、ShadowRoot、映射记录和已保存命中文字的数量不另设搜索配额。字符数统计已读取的原文，选区之外的文字不占选区扫描预算。字符预算或匹配上限用尽时，保留已确认且通过复核的结果，并显示相应原因。计数带 `+` 表示搜索尚未完成，即使没有命中也显示 `0+`。查询超时会报告超时并清理未发布的标记。

普通文本和不含正则元字符的非空表达式连续分片匹配，支持跨片命中，不把全部扫描内容拼成一条字符串。复杂正则收到完整逻辑文本块后才执行原生匹配，保留锚点、环视和回引的完整语义。传输按最多 16 Mi 字符的消息分片并逐批确认，超过这一大小的逻辑文本块会继续传输。浏览器自身的字符串或正则引擎仍有容量限制；文本超出引擎能力时报告错误 `414`，表达式编译或执行失败也会报告具体错误，随后可缩小选区或调整查询重试。

采集按每份至多 128 Ki 原字符的来源记录保存空白折叠和显示变换信息；只在收到命中位置后，恢复命中涉及的原文范围。结果共享原字符串快照，保存节点和 UTF-16 偏移，高亮与校验不复制整段匹配文字。控件选区也保存原值引用，查询前核对控件类型和原值。完成、取消或失败时释放不再使用的来源记录。密集空白的位置恢复使用相对当前来源片段的整数数组，原文绝对偏移仍保留完整精度；密集命中共享导航方法及每轮样式检查缓存。原生高亮显示后，页面变化记录也会分片处理，避免未再次定位时长期保留已删除的节点。

DOM 遍历和文本准备按访问节点及字符数量进行。短字面查询使用浏览器原生匹配；长 ASCII 查询先找固定长度的短片段，再核对完整查询，重复失败后回退到线性 KMP，不对超长查询直接反复执行全文字符串查找。Unicode 回退保留原生大小写和 UTF-16 位置语义。复杂正则最坏情况下仍可能回溯，不能承诺任意表达式都具有线性复杂度。采集、传输和渲染分片执行，取消会释放任务和高亮资源。

浏览器支持时使用原生文本高亮；兼容绘制使用两层可复用的视口 Canvas，逐帧处理全部可见矩形，切换当前项或滚动不重新分配画布。视口尺寸变化才调整像素缓冲，关闭时释放；Canvas 不可用时继续分帧绘制 DOM 矩形。

## 开发和验证

开发需要 Node.js 22 或更新版本。

公共查询和传输约束集中在 `domain/runtime_policy.js`，设置页与配置校验共用 `RRRuntimeConfig.numericRanges` 和 `budgetPresets`。传输窗口、缓存容量和分片批量只控制一次工作的资源占用，不能当作搜索范围上限。模块内部按用途命名调度参数；动态观察在批量用尽后继续处理剩余变更记录，停止时释放队列。

```sh
npm ci
npm run lint
npm test
npm run test:integration
npx playwright install chromium
npm run test:browser
npm run build
```

`lint` 对全部 JavaScript 源文件分别运行语法检查。单元测试验证规则、配置和界面事件；集成测试验证真实模块、Worker 协议、取消、超时、资源上限及生命周期。浏览器测试加载实际 MV3 扩展，使用仅授权本地测试地址的独立副本，覆盖严格 CSP、页面范围、动态变化、节点身份、高亮清理、恶意查询超时，以及键盘操作、设置读取失败、不同窗口尺寸和定位稳定性。测试权限不会进入运行包。

构建输出 `dist/` 和 `dist/regex-rabbit.zip`，包含 `search_worker.js`、offscreen 文档和全部运行模块。可在 `chrome://extensions` 开启开发者模式后加载 `dist/`；更新已有安装后需要重新加载扩展和页面。

模块接口和维护约束见 [AGENTS.md](AGENTS.md)。offscreen 生命周期与权限依据 [Chrome offscreen API](https://developer.chrome.com/docs/extensions/reference/api/offscreen)，搜索栏样式来源依据 [Chrome scripting API](https://developer.chrome.com/docs/extensions/reference/api/scripting#type-CSSInjection)，不改写 DOM 的高亮依据 [CSS Custom Highlight API](https://developer.mozilla.org/en-US/docs/Web/API/CSS_Custom_Highlight_API)。
